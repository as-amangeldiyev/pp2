# TSIS 2 Paint

Install Pygame with `python -m pip install -r requirements.txt`, then run `python paint.py` from this folder.

Choose tools and colors from the toolbar. Use **1**, **2**, or **3** to select a 2, 5, or 10 pixel brush. Press **Ctrl+S** to save a timestamped PNG in `saves/`. For text, click the canvas, type, press **Enter** to place it, or **Escape** to cancel. Press **Escape** when text is not being edited to close the app.
