# Practice 3: Python Functions and Object-Oriented Programming

This project contains runnable examples for Python functions, lambda expressions, classes, and inheritance.

## Structure

- `functions/` covers basic functions, arguments, return values, and `*args` / `**kwargs`.
- `lambda/` covers basic lambdas and their use with `map()`, `filter()`, and `sorted()`.
- `classes/` covers class definitions, constructors, instance methods, and class versus instance variables.
- `inheritance/` covers basic inheritance, `super()`, method overriding, and multiple inheritance.

## Running an example

Run any file from the repository root, for example:

```bash
python3 Practice3/functions/basic_functions.py
```

Each file is self-contained and prints its result. The requested `Practice-Tasks-Set` files were not present in this repository when this practice was created.
